## Документы этапов (SVG + PDF)

`ekd/` — новый путь производства документов курсового проекта: лист ЕСКД, из которого
**за один запуск** выходят и SVG, и PDF с одной и той же геометрией, линиями и текстом.
Существующий конвейер чертежа (`guide_drawing.py`) умеет только PDF, несёт ISO-штамп
вместо основной надписи и не знает символики ГОСТ 3.1107-81 — документы этапов
строятся здесь.

| Скрипт | Артефакт | Что это |
| --- | --- | --- |
| basing_scheme.py | `3865.00.10_SB/01_Схема_базирования/Схема_базирования.svg` и `.pdf` | Схема базирования направляющей по схеме УНО: шесть опорных точек 1–6 |

- `ekd/primitives.py` — примитивы листа (отрезок, окружность, надпись) и метрики надписей
  по ГОСТ 2.304.
- `ekd/sheet.py` — лист: рамка по ГОСТ 2.301, основная надпись по ГОСТ 2.104 (форма 1),
  дополнительные графы и два вывода из одного источника (SVG и PDF — из одного разложения
  листа на отрезки, окружности и надписи).
- `ekd/projection.py` — виды изделия: HLR-проекция модели (build123d) и перевод точек
  модели в миллиметры листа.
- `ekd/symbols.py` — условные обозначения опор по ГОСТ 3.1107-81.

```bash
uv run python src/basing_scheme.py     # пишет SVG и PDF в папку этапа
uv run pytest                          # проверки листа и схемы
```

Зависимости (cadgen, matplotlib) и интерпретатор ставит uv по `pyproject.toml`:
в системном Python cadgen нет, поэтому `python src/basing_scheme.py` без `uv run` падает
с `ModuleNotFoundError: cadgen`.

## Расчёт размерных цепей

| Скрипт | Артефакт | Что это |
| --- | --- | --- |
| dimensional_chains.py | `3865.00.10_SB/Размерные_цепи/Расчёт_размерных_цепей.md` и `razmernye-tsepi.json` | Размерные цепи приспособления: замыкающее звено, допуск приспособления, координаты опор, упоров и зажимов |

Зависимостей нет — хватает системного Python:

```bash
python src/dimensional_chains.py                      # документ и JSON с одними числами
python -m unittest tests.test_dimensional_chains      # проверки расчёта
```

Числа не вводятся в документ руками: и документ, и JSON собираются из структур скрипта,
поэтому результат воспроизводим — тест сверяет пересборку с файлами в репозитории.
Допуски приспособления выведены из допусков изделия по правилу «в 2…3 раза жёстче»
(цепь приспособления MΔ = M3 + M1 + M2), поверки — максимум-минимум и вероятностным
способом. Подробности — в `3865.00.10_SB/Размерные_цепи/README.md`.
