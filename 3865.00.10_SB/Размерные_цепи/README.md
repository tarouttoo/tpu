# Расчёт размерных цепей приспособления

Артефакт: `Расчёт_размерных_цепей.md` и `razmernye-tsepi.json` — одни и те же числа
в читаемом документе и в машиночитаемом виде (JSON — вход для принципиальной схемы
приспособления). Собираются одним запуском, без зависимостей:

```bash
python src/dimensional_chains.py
```

## Как считается

Задача прямая (проектная): по допуску исходного звена (124 +0,5) назначить допуски
приспособления — правило «допуск приспособления в 2…3 раза жёстче допуска изделия»
(пособие, п. 2.3.6). Размерная цепь приспособления построена как MΔ = M3 + M1 + M2 —
размер приспособления плюс две погрешности базирования (табл. 2.2 пособия). Поверки —
максимум-минимум и вероятностный способ (k = 1,2; риск брака 0,27 %). Источники и
сверка с теорией — в разделах 6 и 8 документа, методика — лекция 03
(`transcripts/лекции/03. Точность, размерные цепи и расчёт допусков приспособления.md`).

## Что нужно сверить человеку

1. Принятую погрешность базирования 0 (+0,2): она требует, чтобы кромки упоров были
   обработаны, а заготовки прижаты к базам. Без прижима расчёт не сходится даже
   вероятностным способом — это и есть обоснование роли зажимов (раздел 3 документа).
2. Координаты опор: они совпадают с опорными точками 1–6 схемы базирования (этап 1) —
   проверить, что это те же точки, что на листе.
3. Схему фиксации: два внутренних упора задают зазор 124 между Стойками, упоры 9–10
   задают положение Перемычки по длине 135 и откидываются перед сваркой швов.
4. Расхождение с чертежом: ширина 90 на `PDF/guide_drawing.pdf` проставлена как 90 ±0,5,
   а согласованный допуск — 90 −0,5 (см. «Допущения», п. 5).
